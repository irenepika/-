# Output Directory

This directory contains logs, user profiles, and evaluation reports generated by the Insurance Agent Harness system.

## Structure

```
output/
├── logs/                      # 运行日志（按日期分隔的 JSONL 文件）
│   └── run_YYYYMMDD.jsonl    # 审计日志：完整的 Prompt 溯源
├── user_profiles/             # 用户 DISC 画像存储
│   └── {user_id}.json        # 各用户的 DISC 性格侧写
└── evals/                     # 评测报告输出
    ├── benchmark_report_*.json
    ├── benchmark_report_*.md
    └── benchmark_report_*.html
```

## Log Format

Each line in `logs/run_*.jsonl` contains a complete interaction record:

```json
{
  "timestamp": "2025-01-01T12:00:00",
  "user_id": "user_12345",
  "session_id": "session_abc123",
  "user_input": "我想了解一下重疾险",
  "assistant_response": "您好！重疾险是...",
  "state": {
    "customer_temperature": "neutral",
    "funnel_stage": "awareness"
  },
  "profile": {
    "disc_type": "I",
    "interaction_stage": "awareness"
  }
}
```

## User Profile Format

`user_profiles/{user_id}.json` stores the DISC profile:

```json
{
  "user_id": "user_12345",
  "disc_type": "I",
  "interaction_stage": "interest",
  "interaction_style": "热情互动，多讲故事，建立情感连接",
  "decision_factors": ["品牌声誉", "服务保障"],
  "risk_aversion": "medium",
  "evidence": [
    {
      "quote": "我想了解一下这个产品",
      "reason": "开放性问题，表现出探索意愿"
    }
  ],
  "created_at": "2025-01-01T10:00:00",
  "updated_at": "2025-01-01T12:00:00"
}
```

## Evaluation Reports

Benchmark reports are generated in JSON, Markdown, and HTML formats for easy consumption.
